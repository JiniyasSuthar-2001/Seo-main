1. WHAT ARE WE DOING? (PROJECT GOAL & VISION)
--------------------------------------------------------------------------------
We are building a production-grade, local-first SEO Intelligence & Website Audit
Platform. The platform gives website owners, SEO agencies, and developers full
control over their SEO data, crawler analysis, technical audits, keyword tracking,
competitor insights, business context intelligence, and automated executive reporting—
without relying on costly SaaS subscriptions or leaking proprietary data.

KEY CAPABILITIES & CORE MODULES:
  1. Universal Asynchronous Crawler & Parser:
     - High-speed async crawler with configurable depth and concurrency limits.
     - Extracts HTML titles, meta descriptions, robots directives, canonical tags,
       H1-H6 heading hierarchy, open graph tags, image alt texts, and word counts.
     - Maps full internal link graphs and outbound external link profiles.
     - Stores immutable, timestamped JSON snapshot artifacts for historical comparisons.

  2. Automated 14-Point Technical SEO Audit Engine:
     - Detects 404 broken links, missing/suboptimal titles (length checks), missing
       meta descriptions, thin content (<300 words), heading hierarchy violations,
       non-canonical URLs, broken outbound links, and crawlability blockers.
     - Computes an objective 0–100 Website Health Score with issue severity weightings.

  3. Business Context Intelligence Layer:
     - Integrates real business details: Business Name, Industry/Niche, Core Services,
       Target Service Areas/Locations, and Country/Language targets.
     - Automatically infers topic themes from crawled titles/H1s when unconfigured,
       without fabricating unverified business claims.

  4. Batched AI-Powered Solutions & Executive Analysis:
     - Intelligence layer built on top of real SEO crawl data (zero fabricated stats).
     - Resolves user-configured LLM providers (Groq, Google Gemini, OpenAI, Claude,
       or local Ollama) and executes batched analysis prompts.
     - Generates grounded, page-specific AI fixes, future roadmap recommendations,
       executive summaries, and score explanations with transparent "ai_generated" flags.
     - Gracefully falls back to deterministic rule-based templates if offline.

  5. Single-Source-of-Truth Multi-Format Reporting Pipeline:
     - Every export derives strictly from `MasterReportBuilder.build_master_report()`:
       * PDF: Client-ready executive health report via ReportLab with branded styling.
       * XLSX: Multi-sheet workbook with front 📊 Dashboard summary (KPI cards,
         severity rollup, health breakdown) + 10 dedicated category audit sheets.
       * PPTX: Executive slide presentation for client and stakeholder reviews.
       * CSV: Human-readable, structured data exports for spreadsheet analysis.
       * ZIP: Comprehensive data archive containing Master PDF, XLSX, PPTX, CSVs,
         and a data definitions README.
     - Scoped page-specific downloads ensure buttons on individual views (e.g.
       Keywords, Pages, Technical) only download their respective filtered datasets.

  6. Keyword Analysis & Search Suggestions:
     - Frequency-based topic extraction from crawled page contents.
     - Real-time Google Autocomplete query suggestions.

  7. External OAuth 2.0 Integrations & AES-256 Encryption:
     - Secure OAuth 2.0 connectors for Google Search Console, Google Analytics 4,
       Google Ads, Google Calendar, Gmail, and Meta.
     - AES-256 Fernet encrypted key storage at rest with HMAC-SHA256 CSRF protection.

  8. Real-Time UI Ticker & 3-State System Health:
     - Live floating crawl progress overlay displaying page counts and completion state.
     - Header status pill indicating ONLINE, DEGRADED, or OFFLINE backend state.

2. HOW ARE WE DOING IT? (TECHNICAL ARCHITECTURE & STACK)
--------------------------------------------------------------------------------

FRONTEND ARCHITECTURE:
  - Stack: Vanilla JavaScript (ES Modules), HTML5, CSS Custom Design Tokens.
  - Design Philosophy: Lightweight Single Page Application (SPA) with zero heavy
    framework dependencies (no React/Angular build overhead).
  - Dev Server: Custom Python SPA server running on http://localhost:8030.
  - UI Views & Components:
    * Views: Dashboard, Pages, Technical, Keywords, Rankings, Competitors,
      AEO/GEO, Reports, Integrations, Settings, Help.
    * Components: TopBar, Sidebar, CrawlProgressOverlay, ErrorState, Modals.
    * Services: API Client, Crawl Service, Dashboard Service, AI Service.

BACKEND ARCHITECTURE:
  - Framework: FastAPI (Python 3.14 / 3.x) running on http://127.0.0.1:8020.
  - Database: SQLAlchemy ORM with SQLite (backend/seo.db).
  - Config & Settings: pydantic-settings & python-dotenv reading backend/.env.
  - Single Source of Truth: `MasterReportBuilder` (app/services/reports/master_report_service.py).
  - Multi-Format Generators:
    * `PDFReportGenerator` (app/services/reports/pdf_service.py)
    * `XLSXExportService` (app/services/reports/xlsx_service.py)
    * `PPTXExportService` (app/services/reports/pptx_service.py)
    * `CSVExportService` & `ZIPExportService` (app/services/reports/export_service.py)

DATA INTEGRITY POLICY:
  - AI is strictly an analysis and presentation layer—it NEVER invents SEO data.
  - Zero fabricated rankings, zero mock OAuth tokens, and zero fake competitors.
  - When an external integration (GSC, GA4, Backlinks) is not connected, the UI and
    reports clearly state "Data Not Connected" with instructions on how to connect.

4. HOW TO RUN & TEST THE SYSTEM
--------------------------------------------------------------------------------
1. Launch Local Development Environment:
     python start_dev.py

   - Frontend Web App:  http://localhost:8030/
   - Backend REST API:  http://127.0.0.1:8020/
   - Interactive Docs:  http://127.0.0.1:8020/docs

2. Run Automated Regression Test Suites:
   From the backend directory:
     cd backend
     python -m pytest tests/test_master_export_consistency.py tests/test_universal_master_reporting.py tests/test_page_specific_exports.py tests/test_full_master_health_report.py -v
